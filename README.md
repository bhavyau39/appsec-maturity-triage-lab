# Application Security Maturity & Vulnerability Triage Lab

This project is a hands-on lab to simulate how an enterprise security team would manage application security for an Azure-hosted web application.

It focuses on:

- Defining an **Application Security Maturity** model based on OWASP ASVS areas.
- Scanning an Azure-hosted web app using **Nessus Essentials** and curating key findings.
- Turning vulnerabilities into trackable work items in **Azure DevOps Boards**.
- Building a **Power BI** dashboard that combines maturity scores and vulnerability data to support triage and reporting.

## Tech Stack

- Azure Storage Static Website (sample web application)
- Nessus Essentials (vulnerability scanning)
- Azure DevOps Boards (triage workflow)
- Power BI Desktop (dashboards)
- Excel (data curation and maturity model)
- GitHub (documentation and version control)
